# ✨ Overview

REDMAGIC TITAN 16 PRO is a premium frontend engineering project designed to recreate the experience of exploring a high-end gaming laptop through a fully interactive cyberpunk-inspired environment.

Unlike traditional product pages, this project transforms hardware presentation into an immersive digital experience using modern web technologies and real-time interactions.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/praneetkamble/Redmagic_clone.git
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

## Production Build

```bash
npm run build
```

## Preview Build

```bash
npm run preview
```
