# REDMAGIC Titan 16 Pro - Interactive Cyborg Showcase

A premium, interactive 3D product showcase and real-time performance dashboard for the REDMAGIC Titan 16 Pro gaming laptop. Built with React, Vite, TailwindCSS, Three.js, GSAP, and Web Audio API.

## Features

- **Cyborg Haptic Sound FX**: Interactive Web Audio synthesizer generating custom sci-fi sound effects and interface feedback.
- **3D Chassis Lab**: Fully interactive 3D model orbit viewer with dynamic hinge adjustments, turbine activations, and board lighting.
- **Airflow Particles Sim**: Live simulation of thermal designs and dynamic fan operations.
- **Overclock Performance Dashboard**: Interactive control system mimicking hardware stress testing, CPU/GPU temperature meters, and frame rate monitors.
- **Quantum Color Display**: Responsive color-gamut and high-frequency display demonstration.
- **Coordinate Port Mapping**: Spatial interface highlighting input/output connectivity.
- **Mechanical RGB Keydeck**: Virtual mechanical keyboard testing deck with responsive key actions and customizable lighting profiles.

## Run Locally

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Steps
1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to the printed local port (usually [http://localhost:3000/](http://localhost:3000/) or [http://localhost:3001/](http://localhost:3001/)).
